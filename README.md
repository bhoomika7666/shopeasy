# ShopEasy - Simple E-Commerce Website

A simple e-commerce website built using PHP & MySQL. Users can browse products, add to cart, and checkout. Admin can add/manage products.

## Features
- User Login / Signup
- Product Listing with Images
- Add to Cart / Remove from Cart
- Checkout
- Admin Dashboard - Add / Delete Products
- MySQL Database Integration

## Tech Used
- PHP, MySQL, HTML, CSS, Bootstrap
- XAMPP (Apache + MySQL)

## How to Run
1. Clone this repo: `git clone https://github.com/bhoomika7666/shopeasy.git`
2. Copy folder to `C:/xampp/htdocs/shopeasy`
3. Start Apache & MySQL in XAMPP
4. Create database `shopeasy_db` in phpMyAdmin and import `shopeasy_db.sql`
5. Open in browser: `http://localhost/shopeasy`

## Admin Login
- Go to `http://localhost/shopeasy/admin` or Login page
